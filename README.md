# Dance Content Engine v1

Локальная AI-readable инфраструктура для экспертного контента танцевальной школы.

## Принцип
Система строится вокруг знаний эксперта, исследования рынка, понимания аудитории и управляемого контент-процесса.

## Важное правило
Не создавать новые папки без необходимости. Сначала использовать существующую структуру.

## AI-readable принцип
Каждая папка содержит README.md с назначением, входами, выходами и правилами работы AI.

## Основные потоки
1. Expert Knowledge
2. Research / Radar
3. Audience
4. Content
5. SEO
6. Analytics
7. Automation

Публичный сайт/Next.js размещается в `apps/`.
