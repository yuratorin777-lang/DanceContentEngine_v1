# DOCUMENT RULES

Every substantial document should begin with:
- Title
- Purpose
- Scope
- Status
- Version
- Date
- Owner / Role
- Source basis

For research documents also include:
- methodology;
- sources;
- limitations;
- confidence / uncertainty where relevant.

Never silently overwrite a material result. Create a revision or clearly marked update.

AI must distinguish:
FACT = supported by source or owner input.
INFERENCE = reasoned interpretation.
HYPOTHESIS = not yet verified.
RECOMMENDATION = proposed action based on analysis.
