# NEXT.JS

Здесь будет публичное веб-приложение.

После распаковки проекта можно выполнить из корня:

`cd apps`

`npx create-next-app@latest web`

Рекомендуемый стек для MVP:
- Next.js
- TypeScript
- Tailwind CSS (если нужен)
- без лишней инфраструктуры на первом этапе

Next.js не является всей системой. Это только приложение внутри `apps/web`.
