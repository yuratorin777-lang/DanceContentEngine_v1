# LOCAL SEO RULES

Pilot geography: Serpukhov.

Goal: useful local information coverage, not mass-generated doorway pages.

A local page should contain real local value:
- relevant service;
- actual location/context;
- genuine local information;
- useful answers;
- unique expert material.

Do not create pages solely by replacing a city name.
Do not publish thin duplicate pages.
Search demand is an input to editorial decisions, not permission to generate spam.
